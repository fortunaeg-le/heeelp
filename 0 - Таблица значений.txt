Сообщение 3 (тот же чат)

Помоги настроить учебный стенд по сетям: маршрутизаторы Eltex ESR и Linux ALT. В прошлом сообщении я прислал картинку схемы и текст задания. Заполни по ним ШАБЛОН.

КАК ОТВЕТИТЬ: один блок кода, в нём все строки шаблона в том же порядке. Каждая строка — ровно «метка = значение»: метку копируй буква в букву по-русски (не переводи и не меняй), а всё после «=» (вместе с подсказкой в скобках) замени одним значением. Значение без кавычек и без пояснений. Больше ничего не пиши.

ПРАВИЛА:
- Роли: провайдер = ISP; роутер-1 = HQ-RTR; роутер-2 = BR-RTR; коммутатор = HQ-SW; сервер-1 = HQ-SRV; клиент-1 = HQ-CLI; сервер-2 = BR-SRV.
- Маска сети офиса — ТОЛЬКО по фразе «не более N адресов», строго по таблице: 4→30, 8→29, 16→28, 32→27, 64→26, 128→25, 256→24. N — это число адресов, а не хостов: ничего не прибавляй и не пересчитывай, просто возьми из таблицы. Префикс после адресного пространства (/24, /26, /28 …) для маски НЕ используй: «не более 8 адресов из 10.0.0.0/28» → 29.
- Сеть офиса = адрес адресного пространства из той же фразы без /префикса. Шлюз = сеть, последнее число +1. Хост (сервер, клиент, коммутатор) = сеть, последнее число +2.
- Сети к провайдеру даны готовыми («подключен к сети X/Y»): маска = Y; IP провайдера = сеть +1; внешний IP роутера = сеть +2.
- Туннель: сеть = адрес из пункта про туннель; «минимально возможная маска» = 30; роутер-1 = сеть +1, роутер-2 = сеть +2.
- Порты — со схемы, подпись у конца линии рядом с устройством. ESR — только номер вида 1/0/2 (без gi). Linux — как есть (ens19). У коммутатора три РАЗНЫХ порта: к роутеру-1 — на линии вверх к облаку роутера, к серверу-1 — на линии к облаку серверов, к клиенту-1 — на линии к облаку клиентов.
- Маски пиши только числом (25): без «/» и без точек. Адреса — четыре числа через точку.
- Логины, группы, пароли, пути, текст баннера — посимвольно из текста. Если пароль для чего-то не указан отдельно — бери пароль, данный в задании для пользователей.
- Доп. имена — строки таблицы DNS, где устройство — интерфейс ISP: имя до первой точки; адрес «в сторону HQ-RTR» = IP провайдера к роутеру-1, «в сторону BR-RTR» = IP провайдера к роутеру-2.
- Обратная зона = первые три числа сети в обратном порядке (192.168.10.0 → 10.168.192).
